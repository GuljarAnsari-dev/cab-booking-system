# Cab Booking System

## Project
This is a simple Cab Booking System built using Spring Boot.

## Features
- Book cab
- Enter pickup and drop
- Calculate price

## Technology
- Java
- Spring Boot
- Spring Security
- MySQL
- HTML, CSS, Js

## How to Run
1. Open project in IDE
2. Run main class
3. Open browser: http://localhost:8087
