# 🚖 Cab Booking System

## 📌 Project Overview

The **Cab Booking System** is a web-based application developed using **Spring Boot** that allows users to book cabs easily by selecting pickup and drop locations. The system calculates fares and manages bookings efficiently.

---

## 🚀 Features

* ✅ User Registration & Login
* ✅ Book a Cab (Pickup & Drop Location)
* ✅ Fare Calculation
* ✅ Booking Confirmation
* ✅ Booking History (optional if added)
* ✅ Admin Panel (optional)

---

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone https://github.com/GuljarAnsari-dev/cab-booking-system.git
```

### 2️⃣ Open in IDE

* Open project in **IntelliJ IDEA / Eclipse**

### 3️⃣ Configure Database

Update `application.properties`:

```
spring.datasource.url=jdbc:mysql://localhost:3306/cabdb
spring.datasource.username=root
spring.datasource.password=yourpassword
```

### 4️⃣ Run Project

* Run main class
* Open browser:

```
http://localhost:8080
```
